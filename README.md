# Module 5 – Python Application Development

## Student Management API

This project is developed using Python, FastAPI, and SQLite.

### Features
- Add student details
- View student records
- Update student details
- Delete student details
- Validate student names and marks
- Store data using an SQLite database

### Technologies Used
- Python
- FastAPI
- SQLite
- SQL
- Uvicorn

### How to Run
1. Install the required libraries:
   `pip install fastapi uvicorn`
2. Run the application:
   `uvicorn module5:app --reload`
3. Open `http://127.0.0.1:8000/docs` in your browser.

### Learning Outcome
Learned to create REST API endpoints, validate data, and perform database CRUD operations.
